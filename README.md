# 🦠 COVID-19 Data Cleaning, EDA & Machine Learning
An end-to-end Data Analytics project analyzing global COVID-19 metrics using Python, Pandas, Seaborn, and Scikit-Learn.
## 📌 Project Overview
- **Data Preprocessing:** Cleaned missing values across population, tests, recoveries, and deaths. Filtered out summary rows to prevent double-counting.
- **Exploratory Data Analysis:** Analyzed continent-wise distribution, top affected countries, and correlation metrics.
- **Visual Dashboards:** Built multi-panel visual reports for key findings.
- **Machine Learning:** Classified countries into Risk Categories (*High*, *Medium*, *Low*) using Random Forest Classification.
## 🛠️ Tech Stack
- Python 3.x
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-Learn
- Jupyter Notebook
